## HOW TO USE THIS CHECKLIST

This is a **self-assessment**, not an audit. Score yourself honestly: ✅ Yes, 🟡 Partial, ❌ No.

**Scoring:**
- All ✅ = You're likely 75–90% ready for a real GSTC audit
- Many 🟡 = You're 50–75% ready; focus on gaps first
- Many ❌ = You're 25–50% ready; start with basics

**Next step:** Book a Readiness Snapshot to identify priority gaps and timelines.
